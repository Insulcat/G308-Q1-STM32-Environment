# 第五题：二自由度舵机云台

本目录对应《考核题 V2.0》软件部分第五题。系统由主控端和舵机执行端两套 STM32F103C8T6 工程组成，通过两块 HC-05 蓝牙模块无线通信，并使用 FreeRTOS 组织输入、通信、接收和舵机控制任务。

## 功能实现

- PA0、PA1 分别采集两个电位器，控制水平和俯仰目标角度。
- MPU6050 通过 I2C2 获取姿态，互补滤波计算横滚角和俯仰角。
- PA2 按键可在电位器模式和 MPU6050 姿态模式之间实时切换。
- 主控端每 20 ms 通过 USART1/HC-05 发送带帧头、序号和异或校验的 8 字节数据包。
- 从机端以中断加消息队列接收数据，校验后由 TIM2_CH1、TIM2_CH2 输出 50 Hz PWM 驱动两个 SG90 舵机。
- 通信超时 500 ms 时，执行端自动使两个舵机平滑回到 90° 中位。
- 两端都基于 FreeRTOS；共享状态通过互斥量保护。

## 实机验收结果

- 两块 HC-05 已完成主从绑定，连接后约每两秒同步闪烁两下。
- 电位器模式下，PA0 对应底座水平舵机，PA1 对应上层俯仰舵机。
- MPU6050 模式下，主控面包板左右倾斜控制水平轴，前后俯仰控制俯仰轴。
- PA2 可在运行中切换两种控制方式。
- 两个舵机均能平稳转动并保持目标位置，组装后无持续碰撞或机械卡滞。
