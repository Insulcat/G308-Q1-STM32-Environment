## 功能说明

VOFA+ 通过 CP2102 与 STM32 的 USART1 通信，发送目标角度命令后，STM32 使用 TIM2_CH1（PA0）输出 50 Hz PWM 控制 SG90 舵机，并通过 JustFloat 协议回传程序控制角度和 PWM 占空比。

串口配置：COM7、115200 bit/s、8N1、无流控。

命令示例：

```text
A45
A90
A135
```

发送结尾选择换行符 `\n`。对应测试结果如下：

| 命令 | 角度 | PWM 占空比 | 结果 |
|---|---:|---:|---|
| A45 | 45° | 6.25% | 舵机到位后稳定 |
| A90 | 90° | 7.50% | 舵机到位后稳定 |
| A135 | 135° | 8.75% | 舵机到位后稳定 |

## 重要接线

- CP2102 TXD → PA10，RXD → PA9，GND → STM32 GND；CP2102 的 5V 和 3V3 不接。
- 舵机信号线 → PA0；舵机红线 → 外部 5V；舵机棕线 → 外部 GND。
- STM32 GND、CP2102 GND、舵机 GND 和外部电源负极必须共地。
- 外部适配器标称 5V/3A，实测输出 5.03V。

## 说明

普通 SG90 没有向 STM32 提供独立位置反馈，因此 VOFA+ 的 `I0` 表示程序当前控制角度，不是传感器测得的实际轴角；`I1` 表示 PWM 占空比。
