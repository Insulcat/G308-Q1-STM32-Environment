# 硬件第二题设计说明：24V 转 5V 降压模块

## 1. 设计目标与范围

输入标称 24V，输出目标 5V、1A，采用 XT30 输入接口。使用嘉立创 EDA 专业版完成原理图及双层 PCB，板框尺寸约 38.1 × 34.925mm。本次没有仿真、制板或实测；电压、电流、效率及纹波均不作为已验证指标。

## 2. 三种方案比较

| 方案 | 成本与外围 | 实现难度和取舍 |
|---|---|---|
| 线性稳压（例如 7805 类方案） | 控制器外围简单，但大压差下需要显著散热投入 | 24V→5V、1A 时理论损耗约 19W，理想效率约 20.8%，不适合本目标；具体器件还需核对输入额定值 |
| LM2596-5.0 非同步 Buck | 内部开关与补偿，外接肖特基、电感和滤波电容；低频使磁性器件较大 | 固定5V无需反馈分压，参考资料完整，容易绘制、检查，选择此方案 |
| LMR51430 同步 Buck | 集成上下桥开关，省外部续流二极管，需分压和自举等外围 | 可实现更紧凑的方案，但小封装和较高开关频率对布局要求更高，设计核验工作更多 |

本次综合元件数量、散热配套和完成时间，认为 LM2596 固定5V方案最容易实现，并有利于控制本次设计投入。未取得同批次采购报价，以上为定性成本比较，不宣称实际 BOM 总价最低。

## 3. 选型与连接

| 位号 | 提交图纸标注/器件 | 作用 |
|---|---|---|
| U1 | LM2596SX-5.0/NOPB | 固定5V降压，150kHz，器件支持最高40V工作输入 |
| CN1 | XT30UPB-M | 2脚接24V_IN，1脚接GND |
| C1 | 470μF/50V | 输入储能与滤波 |
| C3 | 100nF/50V | 输入高频旁路 |
| D1 | SS56 | 续流肖特基，阴极接开关节点、阳极接地 |
| L1 | 100μH，BOM为PNR6045-101-M | 储能电感，具体电流能力与封装匹配仍需按原厂资料核验 |
| C2 | 220μF/25V，低ESR标注 | 输出滤波，实际ESR需核验 |
| U2 | 两针排针 | 1脚5V_OUT，2脚GND |

U1 的1脚接输入；2脚经 L1 接5V输出；4脚反馈取电感后的输出网络；3脚、5脚及封装散热焊盘6脚接地。固定5V版本无需外接反馈分压。

## 4. 简要计算与工作原理

开关导通时输入向电感与负载供能，关断时电感通过 D1 续流，C2 平滑输出，内部反馈调节占空比。

按理想 Buck 估算：D≈5/24≈20.8%。以150kHz、100μH计算，电感纹波电流 ΔI≈(24−5)×D/(L×f)≈0.264A；1A负载时峰值约1.132A。这不包含频率/电感公差、开关压降、启动及故障情况，不替代电感额定/饱和电流和温升核验。输出目标功率为5W。

## 5. PCB 与局限

用户提交截图显示板框已识别，DRC为0问题。现版采用顶面主要走线和铺铜，底面图由 PCB PDF 第5页转换，按导出内容保留，未人为补画底层铜皮或走线。

现版仍存在 D1、L1 与芯片距离较远、输入旁路回路较长以及反馈线靠近开关回路等布局优化空间。已阅读的官方建议要求功率回路短而宽、元件靠近芯片、避免开关噪声耦合反馈；本次保持现有设计成果，不声称完成该方面优化。后续制作前应核验封装、器件参数、回路布局、热设计及负载能力。
